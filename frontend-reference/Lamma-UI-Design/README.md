# لمّة · Lamma — UI/UX Design v1

**تصميم واجهة منصة لمّة**، مبني محليًا بالكامل. Figma للشاشات النهائية بس.

## كيف تفتحه
لازم تشغّل سيرفر محلي صغير، لأن المتصفح ما بيحمّل الخطوط والملفات من `file://`. من داخل هاد المجلد:

```bash
python serve.py
```

> **مهم:** لا تستخدم `python -m http.server` على هاد الجهاز. بيقطع الملفات اللي أكبر من 64KB، فبتختفي الشاشات وبيضل السايد بار بس. `serve.py` بيبعث كل ملف كامل، ومن غير كاش.

بعدين افتح هاي الروابط:

| الرابط | شو فيه |
|---|---|
| http://127.0.0.1:5180/app/index.html | **البروتوتايب**: كل الشاشات قابلة للضغط |
| http://127.0.0.1:5180/app/index.html#/screens | فهرس الـ 40 شاشة وحالة |
| http://127.0.0.1:5180/design-system/components.html | مكتبة المكونات بكل حالاتها |
| http://127.0.0.1:5180/docs/ux-architecture.html | خريطة الموقع والـ 16 رحلة |

> **إذا ما ظهر تعديل جديد بالمتصفح:** اعمل تحديث قوي بـ Ctrl + Shift + R.

| — · القائمة الجانبية | طبقات، مؤشر بينزلق، مجموعات، قوائم فرعية بخيط، بطاقة التجربة، وضع مصغّر | `lamma.css` (`.sb`) · `app.js` |

| 5 · المنتجات والمخزون | قوالب ومعاينة حيّة، خريطة المقاسات، استلام وتعديل حقيقيين، سجل حركات | `catalog.css` |
| 6 · العملاء والمالية والتقارير | تصنيفات العملاء، ملف العميل، دفتر المالية، عمر الذمم، شلال الربح | `money.css` |
| 7 · الباقي والفحص | الدخول والتهيئة والإعدادات والاشتراك والحالات، وفحص موبايل وتابلت واتجاه LTR | `shell.css` |

**قواعد العمل كلها بمكان واحد:** `App.setStatus` (حجز عند التأكيد، خصم عند التوصيل، فك عند الإلغاء) مع «تراجع».
**تقليل الحركة:** كل ملف فيه قواعد `prefers-reduced-motion`، وفوقهم شبكة أمان عامة بآخر `shell.css`.
**معاينة الإنجليزي (LTR):** الحساب ← «معاينة الاتجاه LTR».

## v2.1 — تعديلات بعد المراجعة
- **الخلفية:** ضباب زيتي هادي `#EFF1EB` بدل الكريمي (`--lamma-mist-100`). الكريمي ضل للهوية والنصوص على الغامق.
- **القائمة الجانبية:** أعرض (276px).
- **البحث:** شريط زيتي فيه وهج مشمشي بيلف حوله، ونصائح بتتبدّل كل 3 ثواني، واختصار Ctrl K.
- **الجداول:** صفوف عايمة بزوايا مدوّرة على صينية ناعمة، وبتطلع ورا بعض.
- **الرئيسية:** إعلانين: الأول بيعرض 3 ميزات بتتبدّل لحالها، وكل وحدة برسمتها. الثاني للاشتراك، بأيام التجربة.
- **ستيكرات:** ملصقات لمّة على بطاقات (الرئيسية، الأكثر مبيعًا، المالية، والإعلانات)، وستيكر بيطلّ من طرف الشاشة مع جملة حسب الصفحة.
- **الملفات:** `design-system/extras.css`، والستيكرات بـ `illustrations.js` (`LammaArt.sticker`).
